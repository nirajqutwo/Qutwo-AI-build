# qutwo-ai-sdk

Python bindings for the qutwo-ai Development Kit (GDK).

This package is generated from the Rust `qutwo-ai-sdk` crate using UniFFI.

## Build a local wheel

From the repository root:

```bash
just --justfile crates/qutwo-ai-sdk/justfile python-wheel
```

The wheel is written to `crates/qutwo-ai-sdk/python/dist/`.
